# 🤖 Sigma GPT

Sigma GPT is a full-stack AI chatbot application built using the MERN stack. It provides a modern and interactive chat experience with secure user authentication, real-time communication, and scalable backend architecture.

---

# 🚀 Live Demo

🌐 Live Link: [https://sigma-gpt-1.vercel.app/chat](https://sigma-gpt-1.vercel.app/chat)

---

# ✨ Features

* 🔐 User Authentication (Sign Up & Login)
* 💬 Interactive AI Chat Interface
* ⚡ Real-time Conversations
* 📱 Responsive UI Design
* 🗄️ MongoDB Database Integration
* 🔄 Session Management
* 🚀 Scalable Backend Architecture
* 🌐 MERN Stack Based Application
